# java-mini-projects
A collection of beginner-friendly Java mini projects and console applications demonstrating core programming concepts such as Object-Oriented Programming (OOP), Collections Framework, Exception Handling, Interfaces, String Manipulation, and Data Structures. These projects are built for learning and strengthening Java development fundamentals.

A collection of beginner-friendly Java console applications demonstrating:

- Object-Oriented Programming
- Interfaces
- Exception Handling
- Collections Framework
- String Manipulation
- Sorting Techniques
- Payment Simulations

## Projects Included

| Project | Concepts Used |
|---|---|
| Calculator System | Classes, Methods, Switch Case |
| Sorting Utility | Arrays, Collections |
| String Operations | StringBuilder, String Functions |
| Product Discount System | Inheritance, Method Overriding |
| Payment Gateway Simulation | Interfaces |
| Login Authentication System | Custom Exceptions |
| Inventory Management System | ArrayList, Comparator |
| Employee Record System | HashMap, Sorting |

## Technologies

- Java

- Collections Framework
