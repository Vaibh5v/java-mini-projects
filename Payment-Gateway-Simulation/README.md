# Payment Gateway Simulation

A Java console-based application that simulates online payment processing using Card Payments and UPI Payments with refund functionality.

## Features

- Process Card Payments
- Process UPI Payments
- Refund functionality
- Card number masking
- UPI ID validation
- Payment amount validation
- Time-based refund system
- Menu-driven console interface

## Concepts Used

- Interfaces
- Interface Implementation
- Classes and Objects
- Method Overriding
- Conditional Statements
- System Time Handling
- User Input using Scanner

## Technologies Used

- Java
- OOP Concepts
- Interfaces
