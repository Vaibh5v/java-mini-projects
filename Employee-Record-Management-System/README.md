# Employee Record Management System

A Java console-based application that manages employee records using HashMap and sorting techniques. The system supports adding, updating, deleting, searching, and sorting employee data efficiently.

## Features

- Add new employee records
- Update existing employee details
- Delete employee records
- Search employees by ID
- Sort employees alphabetically by name
- Duplicate ID and name validation
- Menu-driven console interface

## Concepts Used

- HashMap
- Collections Framework
- ArrayList
- Map Interface
- Lambda Expressions
- Sorting Techniques
- Classes and Objects
- User Input using Scanner

## Technologies Used

- Java
- OOP Concepts
- Collections Framework
