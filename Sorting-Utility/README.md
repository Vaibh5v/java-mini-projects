# Sorting Utility

A Java console-based application that performs sorting operations on Integer arrays and String arrays in both ascending and descending order.

## Features

- Sort Integer Array in Ascending Order
- Sort Integer Array in Descending Order
- Sort String Array in Ascending Order
- Sort String Array in Descending Order
- Menu-driven console interface
- Dynamic array input from user

## Concepts Used

- Arrays
- Collections Framework
- Arrays.sort()
- Collections.reverseOrder()
- Classes and Objects
- Methods
- User Input using Scanner
- Menu-driven Programming

## Technologies Used

- Java
- Collections Framework
- OOP Concepts
