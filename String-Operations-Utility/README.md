# String Operations Utility

A Java console-based application that performs various string manipulation operations such as counting vowels and consonants, replacing spaces, changing letter cases, and reversing strings.

## Features

- Count Vowels and Consonants
- Replace Spaces with Special Characters
- Convert String to Uppercase
- Convert String to Lowercase
- Reverse String using StringBuilder
- Menu-driven console interface

## Concepts Used

- Strings
- String Methods
- StringBuilder
- Classes and Objects
- Methods
- Loops
- Conditional Statements
- User Input using Scanner

## Technologies Used

- Java
- OOP Concepts
