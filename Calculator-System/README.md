# Calculator System

A simple Java console-based calculator application that performs basic arithmetic operations using Object-Oriented Programming concepts.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Remainder Calculation
- Menu-driven console interface
- Division-by-zero handling

## Concepts Used

- Classes and Objects
- Constructors
- Methods
- Switch Case
- Loops
- User Input using Scanner
- Conditional Statements

## Technologies Used

- Java
- OOP Concepts
