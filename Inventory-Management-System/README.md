# Inventory Management System

A Java console-based application that manages product inventory using ArrayList and sorting techniques. The system allows adding, updating, removing, and sorting products dynamically.

## Features

- Add new products
- Update product prices
- Remove existing products
- Sort products by price
- Sort products alphabetically by name
- Duplicate product ID validation
- Menu-driven console interface

## Concepts Used

- ArrayList
- Collections Framework
- Comparator
- Lambda Expressions
- Classes and Objects
- Method Overriding
- User Input using Scanner

## Technologies Used

- Java
- OOP Concepts
- Collections Framework
