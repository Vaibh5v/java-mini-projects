# Product Discount Management System

A Java console-based application that simulates a product management system with different product categories and discount calculations using inheritance and method overriding.

## Features

- Manage different product categories
- Electronics product handling
- Clothing product handling
- Grocery product handling
- Apply category-wise discounts
- Display updated product details
- Menu-driven console interface

## Concepts Used

- Inheritance
- Method Overriding
- Constructors
- Classes and Objects
- Polymorphism
- Conditional Statements
- User Input using Scanner

## Technologies Used

- Java
- OOP Concepts
