# Login Authentication System

A Java console-based application that simulates a user login system using custom exception handling and credential validation.

## Features

- User login authentication
- Custom exception handling
- Invalid credential detection
- Null input handling
- Secure login validation
- Console-based interaction

## Concepts Used

- Exception Handling
- Custom Exceptions
- Try-Catch-Finally Blocks
- Classes and Objects
- Static Methods
- Conditional Statements
- User Input using Scanner

## Technologies Used

- Java
- OOP Concepts
- Exception Handling
